# SuperExchange

The Communication plane's server side: a Matrix Application Service that carries board work
into chat and the answers back. Gates, board questions and board rooms move here from the
AgentPod hub.

## What will live here

- **Gate and question projection:** a gate or question on a board appears in its room, and an
  answer given in chat reaches the board.
- **Board rooms:** created and kept in step with their boards.

Agent puppeting stays in AgentPod, and the push gateway moves to SuperMessage.
